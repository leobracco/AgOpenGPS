# Agro Parallel icon set

SVG icons for the Agro Parallel platform UI.

Current production candidates are copied from existing project icon folders,
mainly `SourceCode/GPS/btnImages/PilotXVariants`, `SourceCode/GPS/btnImages`,
`SourceCode/GPS/btnImages_pilotx`, and `SourceCode/AgIO/Source/btnImages`.
The generated SVG drafts are kept in this folder only as experiments.

Style:
- 24 x 24 viewBox
- rounded 2 px line work
- carbon stroke `#101612`
- Agro Parallel green accent `#4ABA3E`
- simple, technical, recognizable shapes

Files:
- `agp-icons.json` maps stable platform ids to SVG files.
- `agp-icons.js` exposes the same manifest for local `file://` preview.
- `index.html` is a visual catalog for reviewing the full icon family.
- `existing/` contains PNG copies from the real app icon folders.
- `existing-preview.png` is a contact sheet of the selected PNGs.
- `Tools/apply-existing-webui-icons.ps1` reapplies the existing icon mapping.
- `Tools/generate-webui-icon-set.ps1` regenerates the rejected SVG draft set.
